## ✨ Features

- 🎬 Plays almost any video format (libVLC engine)
- 🫧 Frosted-glass controls that live-blur the video behind them
- 📚 Automatic series playlists: episodes like `Show S01E01` are grouped, played in order and auto-advance
- 📂 Built-in library that finds every video on your phone
- 📝 Subtitles and audio tracks, plus adding your own .srt file
- 📺 Cast to Chromecast devices (experimental)
- ⏩ Double-tap to seek 10 seconds, speed from 0.5x to 2x
- 🔄 One-tap screen rotation
- 🎨 Themes: Material You (follows your wallpaper), Ocean, Sunset, Forest, Rose, Violet and AMOLED black

## 📥 Install

1. Open the **Releases** page and download the latest `.apk`.
2. Tap the file to install it (allow "install unknown apps" if Android asks).

**Requirements:** Android 7.0+ on a 64-bit (arm64) phone.

## 📚 Series naming

Name your files like `The Show S01E01.mkv`, `The Show 1x02.mp4` or `The Show - 03.mkv`. With two or more episodes of the same show, they appear together in the **Series** section.
